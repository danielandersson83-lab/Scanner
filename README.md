# Rums- och streckkodsscanner (GitHub Pages)

1. Skapa ett nytt repo på GitHub, t.ex. `scanner`.
2. Ladda upp filerna:
   - `index.html`
   - `manifest.webmanifest`
   - `sw.js`
3. Gå till **Settings → Pages** i GitHub.
4. Välj:
   - Source: `Deploy from a branch`
   - Branch: `main` (root)
5. Spara. Efter någon minut får du en GitHub Pages-URL, t.ex.:  
   `https://dittkonto.github.io/scanner/`

På iPhone:
- Öppna URL:en i Safari.
- Gå till Dela-ikonen.
- Välj **Lägg till på hemskärmen**.
- Starta appen från hemskärmen för bästa upplevelse.
